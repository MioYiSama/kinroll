技术栈：Kotlin Multiplatform + Compose Multiplatform + 部分Swift接入平台接口

kotlin 2.4.21 + gradle 9.8.2

标识符：`net.mioyi.kinroll`

平台：Android+iOS

分发：apk + unsigned ipa

模型：

- MobileCLIP-S2: [HF](https://huggingface.co/apple/MobileCLIP-S2)
- PaddleOCR: [Android](https://www.paddleocr.ai/main/version3.x/inference_deployment/cross_platform/android_deployment.html) [iOS](https://www.paddleocr.ai/main/version3.x/inference_deployment/cross_platform/ios_deployment.html)
- Qwen 3.5 0.8B: [HF unsloth](https://huggingface.co/unsloth/Qwen3.5-0.8B-GGUF) UD-Q4_K_XL

数据库表：

photo：唯一标识符、元数据（图片本身的元数据和可通过操作系统接口获得的元数据）、CLIP结果、OCR结果、哈希、向量等

界面：

- 中英文、深色模式
- 首次进入，提示权限授权和下载模型（国内提供modelscope/hf-mirror下载选项）
- 主界面展示三个入口：图片清理（截图、保存图、废片）、图片概览（分类、检索）、帖文生成（手动选图片然后用LLM生成文案）。展示一个索引进度条。
